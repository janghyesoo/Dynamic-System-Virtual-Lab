3. Where Does the Differential Equation Come From?
Mass — Newton's 2nd Law
ΣF = ma = m ẍ
Net force causes acceleration. For the same force, more mass → less acceleration.
Spring — Hooke's Law
Fₛ = −kx
A spring resists displacement. Larger k → more restoring force for the same displacement.
Damper — Viscous Damping
Fᵦ = −b ẋ
A damper resists velocity. Faster motion → larger damping force.
Mass: Newton's second law says the sum of all forces acting on the mass equals mass times acceleration. Acceleration is ẍ, the second derivative of position.
ΣF = m ẍ→F(t) − kx − b ẋ = m ẍ→m ẍ + b ẋ + kx = F(t)

Why does gravity disappear?
Take downward displacement as positive. Let δ be the total spring extension from its unstretched length.
m ẍ = mg + F(t) − b ẋ − kδ
At static equilibrium:   kδ₀ = mg
Let δ = δ₀ + x, where x is displacement from static equilibrium.
m ẍ = mg + F(t) − b ẋ − k(δ₀ + x)
mg − kδ₀ = 0   ⇒   m ẍ + b ẋ + kx = F(t)
Gravity is not ignored. It sets the static equilibrium position; it cancels from the dynamic equation when x is measured from that equilibrium.
—
Newton + spring + damper → ODE
Newton:   ΣF = ma = m ẍ
Spring:   Fₛ = −kx
Damper:   Fᵦ = −b ẋ
ΣF = F(t) − kx − b ẋ = m ẍ
m ẍ + b ẋ + kx = F(t)
Mass relates net force to acceleration; the spring reacts to position; the damper reacts to velocity.
—
ODE → transfer function
m ẍ + b ẋ + kx = F(t)
For a transfer function, use zero initial conditions.
m s²X(s) + b sX(s) + kX(s) = F(s)
(ms² + bs + k)X(s) = F(s)
G(s) = X(s)/F(s) = 1/(ms² + bs + k)

ODE → state-space
Choose states:   x₁ = x,   x₂ = ẋ
ẋ₁ = x₂
ẋ₂ = −(k/m)x₁ − (b/m)x₂ + (1/m)F(t)
A = [0   1; −k/m   −b/m],   B = [0; 1/m]
C = [1   0],   D = 0
Nothing physical changed: one second-order ODE became two first-order equations.

Natural frequency ωₙ
ms² + bs + k = 0
Divide by m:   s² + (b/m)s + k/m = 0
Standard form:   s² + 2ζωₙs + ωₙ² = 0
Compare constant terms:   ωₙ² = k/m
ωₙ = √(k/m)
More stiffness raises the natural frequency; more mass lowers it.
—
Damping ratio ζ and critical damping
b/m = 2ζωₙ
ζ = b/(2mωₙ)
Use ωₙ = √(k/m)
ζ = b/(2√(km))
Critical damping ζ = 1   ⇒   bc = 2√(km)
ζ < 1: underdamped • ζ = 1: critically damped • ζ > 1: overdamped.
—
Poles → under / critical / overdamped
s = [−b ± √(b² − 4mk)]/(2m)
Equivalent form:   s = −ζωₙ ± ωₙ√(ζ² − 1)
ζ < 1Complex-conjugate poles → oscillatory decay.
ζ = 1Repeated real pole → fastest non-oscillatory return.
ζ > 1Two real poles → non-oscillatory, typically slower return.
—
Damped natural frequency ωd
For the underdamped case only, 0 ≤ ζ < 1:
s = −ζωₙ ± jωₙ√(1 − ζ²)
ωd = ωₙ√(1 − ζ²)
ωd is the oscillation frequency visible in the decaying time response. It is lower than ωₙ when damping is present.

What are poles and zeros?
G(s) = N(s) / D(s)
Zeros: solve N(s) = 0   •   Poles: solve D(s) = 0
Zeros can suppress or reshape parts of a response. Poles determine the system's natural modes: whether motion decays, grows, or oscillates. This mass–spring–damper has numerator 1, so it has no finite zeros.
Here: D(s) = ms² + bs + k   ⇒   poles = roots of ms² + bs + k = 0
