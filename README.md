# Dynamic System Virtual Laboratory

An interactive, web-based virtual laboratory for studying dynamic systems, developed for ME341 Linear Systems / System Dynamics.

The laboratory is designed to help students connect physical systems with their mathematical representations and dynamic responses through interactive simulation and visualization. Each simulation is fully responsive and runs directly in a web browser without requiring external JavaScript libraries, images, or a server.

## Available Labs

### [Vertical Translational Mass–Spring–Damper System](./vertical-translational-mass-spring-damper/index.html)

An interactive study tool for exploring the dynamics of a vertical translational mass–spring–damper system.

Features include:

- Adjustable mass, damping, stiffness, and external force
- Free, step, pulse, and sinusoidal inputs
- Run/Pause, Reset, and Pull & Release controls
- Interactive mass dragging for initial-condition experiments
- Adjustable simulation speed and input frequency
- Physical and CAD-style system animations
- Real-time displacement, velocity, acceleration, and force
- Time-response visualization
- Governing ODE, transfer function, and state-space representations
- Natural frequency and damping-ratio analysis
- Interactive pole map and pole/zero interpretation
- Stability and oscillation analysis
- Step-by-step symbolic derivations with current numerical values
- Parameter-tuning guidance for improving system response
