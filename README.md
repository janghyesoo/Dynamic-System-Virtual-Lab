# ME341 Virtual System Lab

Interactive, responsive mass-spring-damper study tool for ME341 Linear Systems / System Dynamics.

## Deploy with GitHub Pages
1. Create a GitHub repository (for example `me341-virtual-lab`).
2. Upload `index.html` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will publish the site at the Pages URL shown in Settings → Pages.

The app is self-contained: no external JavaScript libraries, images, or server are required.
